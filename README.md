# Bản cài Solos

Trang này chỉ chứa **file cài đặt** của Solos (không có mã nguồn).

- Tải bản mới nhất: mục **Releases** bên phải → tải file `solos_<phiên bản>_x64-setup.exe` → bấm đúp để cài.
- Solos đã cài sẽ tự báo khi có bản mới và cập nhật một chạm; dữ liệu của bạn được giữ nguyên và sao lưu trước khi cập nhật.
- Mỗi bản cài đều có chữ ký của Solos; app chỉ nhận bản cập nhật có chữ ký đúng.
